## Conceptos aprendidos 
Explique con sus palabras: lista simple, lista doble, lista circular, 

Lista simple solo esta enlazada al elemento siguiente

Lista doble esta enlazada al elemento anterior y al siguiente

Lista circular puede o no tener un fin

ventajas/desventajas de cada una y un ejemplo de uso real. 

Lista Simple: Menos uso de memoria / La lista simple solo se puede recorrer el arreglo en una sola direccion 

Lista Doble: Con lista doble puede recorrer el arreglo hacia delante y hacia atraz / Usa mas memoria por la doble referencia

Lista Circular Puede recorrer el arreglo en un ciclo / si no se define bien la condicion para que se detenga puede entrar en un bucle infinito
